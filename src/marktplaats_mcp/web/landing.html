Marktplaats & 2dehands MCP server

marktplaats-mcp lets Claude, ChatGPT, Cursor, Codex, Gemini and any other MCP client search Marktplaats.nl and 2dehands.be, the Dutch and Belgian second-hand classifieds (tweedehands, petites annonces d'occasion): find bargains, vet sellers, compare prices, watch for new ads, and with your own login read messages, place bids and manage your ads. Free, open source, no API key.

Use it on claude.ai in one step

Settings → Connectors → Add custom connector → paste:

${SITE_URL}/mcp

Works on every Claude plan, including Free, and in the mobile apps. Then ask: "Zoek een racefiets onder €500 in de buurt van 1011 AB en check de verkoper."

Run it locally (adds account tools)

claude mcp add marktplaats -- uvx marktplaats-mcp
uvx --from 'marktplaats-mcp[login]' marktplaats-mcp login   # optional: your own account

The local server imports your Marktplaats session from the browser you are already logged into, so there is no password to type and two-factor login stays in your browser. Config snippets for Claude Desktop, Cursor, VS Code, Codex, Gemini CLI, Windsurf and JetBrains are in the README.
